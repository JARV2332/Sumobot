# SumoBot Academy

Videojuego web de **aprendizaje basado en retos (ABR)** para armar un SumoBot.
Pensado para niños y niñas de 9–13 años, responsive (celular y PC), publicable como sitio estático.

## Cómo abrirlo

1. Abre la carpeta `sumobot-reto-game`
2. Doble clic en `index.html` **o** sirve la carpeta con cualquier servidor estático:

```bash
npx --yes serve .
```

## Publicar

Sube toda la carpeta a:

- GitHub Pages
- Netlify / Cloudflare Pages / Vercel
- Cualquier hosting de archivos estáticos

No necesita backend ni base de datos. El progreso se guarda en el navegador (`localStorage`).
